# Mobile visual direction

The conversation is the main surface. Use generous, readable prose on a near-black
canvas, with neutral user bubbles and restrained harness accents. The reference
set combines ChatGPT's conversation and drawer, Claude's model/task sheets, and
Antigravity's harness/model controls.

## First pass

- One floating composer with the input above a single action row: attach,
  harness, model/effort, voice, send. Walkie mode remains in the drawer.
- Large rounded bottom sheets, explicit close controls, keyboard dismissal and
  focus return. Model and harness choices are keyboard-accessible buttons.
- A wider conversation drawer with search and filters. Voice and permission
  controls sit below the conversation list rather than displacing it.
- 16px body and input text, comfortable line spacing, quieter tool summaries,
  browser zoom enabled, reduced-motion support, and a short-viewport layout.
- Keep real task controls and model capabilities. Never invent usage percentages,
  reset times, or entitlements for visual effect.

## Follow-up direction

Group background tasks into running/finished sections when the backend supplies
that lifecycle reliably. Show context and plan usage only from provider data,
with source and refresh time. Keep account changes distinct from model changes.
A rename is a separate decision; MoE Deck remains the working name.

The committed screenshots use illustrative conversation content and the local
harness/model catalog with mocked network responses. They are layout evidence,
not proof of executing the sample task. Validate on a physical iPhone before
calling keyboard, safe-area, or gesture behavior fully verified.
